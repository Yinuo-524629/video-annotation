# 本地视频批注 · 中文版

[English](README.md) | 简体中文

一款用于 YouTube 和哔哩哔哩的视频批注扩展，方便边看边记录高光时刻、标记片段起止时间，并添加自己的分类和备注。点击批注时间即可跳转回看，还能导出 Excel，逐步积累和整理剪辑素材，让看到的好片段不再被遗忘。

数据保存在浏览器本地，无需账号或后端服务。

## 中文版 / 英文版

| 版本 | 文件夹 | 语言 |
| --- | --- | --- |
| 中文版 | `zh-CN-version/` | 中文界面、提示和 Excel 固定表头 |
| 英文版 | `english-version/` | 英文界面、提示和 Excel 固定表头 |

**当前文件夹：中文版。** 两个版本功能相同，均可独立安装，UI 可自行修改设计。每个版本分别保存本地数据；建议一次只启用一个，避免面板重叠和快捷键冲突。切换前请导出备份，并使用目标版本的模板整理后导入。

## 安装与更新

1. 在 GitHub 仓库点击 **Code → Download ZIP**，下载并解压；也可克隆仓库。
2. 打开 Chrome，地址栏输入 `chrome://extensions/`。
3. 打开右上角的**开发者模式**。
4. 点击**加载已解压的扩展程序**，选择中文版文件夹（当前目录 `plain-version/`）。该文件夹必须直接包含 `manifest.json`，不要选择 ZIP 文件。
5. 打开或刷新 YouTube / 哔哩哔哩的视频页面，右侧会出现批注面板。

修改或更新文件后，在扩展管理页点击该扩展的**重新加载**，再刷新视频页面。直接加载即可，无需安装依赖或执行构建。

## 快速开始：记录一段视频

1. 播放视频，到想标记的位置点击**开始 / Start**。
2. 在**批注内容 / Annotation**填写内容；这是必填项。
3. 如需记录区间，继续播放，到片段末尾点击**结束 / End**。视频不会因此暂停。
4. 按需填写自定义栏。
5. 点击批注表单底部的**保存 / Save**，记录会出现在下方列表，面板自动收起。
6. 点击**导出 XLSX / Export XLSX**下载当前视频的批注。

只记录一个时间点时，结束时间留空即可。

## 功能与具体操作

### 展开、收起、移动和缩放

- 点击标题栏最右侧的按钮展开或收起面板。直接展开也会显示完整表单，并以当前播放位置初始化新批注。
- 单纯收起再展开会保留当前正在填写的表单；切换视频或刷新页面前，请先保存。
- 按住标题栏的空白处拖动面板。按钮区域不会触发拖动。
- 拖动面板**左上角的斜线手柄**调整大小；文字会随面板尺寸在一定范围内放大。
- 支持网页视频全屏；进入全屏后面板会随全屏容器显示。具体行为仍取决于网站播放器。

### 开始时间和结束时间

- 表单关闭时点击**开始**，会新建批注并记录当前播放位置；表单已打开时再次点击，只修改开始时间，不清空内容。
- **结束**只更新结束时间，不暂停视频；未打开表单时请先点击开始。
- 两个时间框均可手动编辑。格式为 `mm:ss` 或 `h:mm:ss`，例如 `02:35`、`1:05:09`；分、秒须符合相应范围。
- 结束时间可为空，也可与开始时间相同；不能早于开始时间。保存和导入时都会校验。
- 自动记录的播放位置以整秒保存。

### 添加文本栏

1. 在批注内容和已有栏位下方点击**＋ 添加栏 / Add field**。
2. 类型选择**文本 / Text**，填写栏位名称，例如“个人想法”。
3. 点击这一栏编辑器内的**保存**，即可在批注表单中使用。
4. 在新增文本框中填写内容；有内容后会出现背景色选项。
5. 点选**无、蓝、粉、红、绿、黄、紫**。默认无色；每条批注可为同一文本栏选择不同颜色。
6. 最后点击批注表单底部的**保存**，保存这条批注的内容和颜色。

### 添加单选栏与选项颜色

1. 点击**＋ 添加栏**，选择**选择（单选） / Select (single choice)**。
2. 填写栏位名称，例如“人物关系”。
3. 在选项名称框输入第一个选项；名称后面的颜色入口默认为**无 / None**。
4. 点击旁边的小色块，展开配色；选择颜色后，名称框会显示对应底色，配色面板自动收起。
5. 点击**＋ 添加选项 / Add option**继续添加。点击对应行的 **×** 删除尚在编辑的选项。
6. 填好全部选项后点击**保存**。至少需要一个选项，选项名称不能为空或重复。
7. 在批注表单中通过**圆点按钮**选择一个选项；选择**不选 / None**可清空选择。每个单选栏一次只能选择一个选项。

### 修改和删除栏位

- 每栏标题旁都有**修改 / Edit**和**删除 / Delete**，无需到另一个栏目列表操作。
- 修改会打开该栏编辑器，可调整名称、类型、选项名称和颜色；点击编辑器内的**保存**生效，点**取消 / Cancel**放弃本次修改。
- **删除栏位立即生效**，并删除当前视频已有批注中这一栏的内容，不需要再保存一次。请先导出需要保留的数据。
- 修改类型会清除当前视频中该栏原类型的值；删除选项会清除已有批注对该选项的选择。
- 栏位数量不设上限；栏位名称不能为空、不能重复，也不能与固定导出列同名。
- 所有自定义栏均为选填。保存的配置会供之后首次打开的新视频沿用；已有视频保持各自的栏位配置。
- **栏位编辑器的保存**用于保存栏位结构；**批注表单底部的保存**用于保存当前一条批注。这两者用途不同。

### 查看、跳转、编辑和删除批注

- 列表按开始时间排序，显示时间点或区间、批注内容和已填写的自定义值。
- 点击一条记录的时间，会跳转到开始位置并播放；不会自动在结束时间停止。
- 点击记录旁的**编辑 / Edit**，修改后保存；文本背景色会回填。
- 点击记录旁的**删除 / Delete**，确认后删除该条记录。
- 点击顶部**清空 / Clear**，确认后删除当前视频的全部记录，保留栏位配置。
- 表单内的**取消**放弃本次批注编辑，不删除已有记录。未保存的表单不会自动持久化。

### 快捷键

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 记录或调整开始时间 | `Ctrl + Shift + .` | `Command + Shift + .` |
| 保存当前批注（焦点在面板内） | `Ctrl + Enter` | `Command + Enter` |
| 取消当前批注编辑（焦点在面板内） | `Esc` | `Esc` |

全局记录快捷键在新建批注时会暂停正在播放的视频；保存或取消后会尝试恢复播放。表单已打开时，快捷键只更新开始时间。顶部的开始、结束按钮不会暂停视频。

如快捷键无效，打开扩展的**选项**页面，点击**打开快捷键设置 / Open shortcut settings**，或直接访问 `chrome://extensions/shortcuts` 检查冲突和分配情况。

## Excel 导出

点击顶部**导出 XLSX**，下载当前视频的全部已保存记录，按开始时间排序。文件名采用视频标题并附加批注标识。

| 中文版固定列 | 英文版固定列 | 含义 |
| --- | --- | --- |
| 开始时间点 | Start time | 必填时间 |
| 结束时间点 | End time | 可为空 |
| 批注内容 | Annotation | 必填内容 |

自定义列按配置顺序追加；列标题来自你填写的栏位名称。单选值与文本背景色会写入对应单元格。时间以文本写出，避免 Excel 自动转换。

文件还附带栏位类型、选项与颜色配置，供本扩展重新导入时使用。经过其他软件编辑并重新保存后，这些附带配置可能被移除；表格数据仍可按表头规则导入，但部分颜色和类型可能无法恢复。

## Excel 导入与空白模板

1. 点击**导入 XLSX / Import XLSX**。
2. 弹窗中选择**确定 / OK**，选取已有 `.xlsx` 文件；选择**取消 / Cancel**则下载当前栏位对应的空白模板。
3. 在模板中每行填写一条批注，保留表头，再保存为 `.xlsx`。
4. 重新点击导入并选择文件。导入会**追加记录**，不会覆盖或自动去重。

中文版要求前面三列为：

```text
开始时间点 | 结束时间点 | 批注内容 | 自定义列……
```

英文版导出并接受：

```text
Start time | End time | Annotation | Custom fields…
```

**请使用对应版本下载的 XLSX 模板导入，保留模板表头和列顺序。** 插件通过前三列固定表头识别格式：开始时间点、结束时间点、批注内容（英文版为 Start time、End time、Annotation）。这里指前三列，不是前三条记录；后面的自定义栏按模板读取，用户填写的名称和正文不会自动翻译。

填写时每行一条记录，结束时间可留空；时间格式为 `mm:ss` 或 `h:mm:ss`。批注内容必填，结束时间不能早于开始时间。空行会忽略，无效记录会跳过并提示行号。导入是追加操作，不会自动去重。请使用 `.xlsx`，不要把其他格式仅改后缀后导入。

**导入插件后，点击批注列表中任意记录的时间，视频会直接跳转到对应的开始时间点并播放。** 需要查看哪个片段，就点击那条记录的时间；不会自动在结束时间停止。

## 本地数据、隐私与自动清理

- 批注使用 `chrome.storage.local` 保存；不同视频分开存储，不依赖服务器，也没有云端同步或账号系统。
- 扩展本身不上传批注；导出的文件由你自行保管或分享。
- 已导出的记录，在导出时间超过 **3 天**后，于扩展处理浏览器启动或安装事件时清理；不是到期精确执行的定时任务。栏位配置会保留，下载到电脑的 Excel 不会删除。
- 新增、编辑、删除记录或修改栏位会重置该视频的已导出标记，需要再次导出才进入新的清理周期。
- 页面可能在离开时提醒未导出记录，但这取决于浏览器规则，不能替代备份。
- 卸载扩展、清除扩展数据或换浏览器配置文件可能丢失本地记录；重要内容请及时导出。
- 哔哩哔哩按 BV/av 视频标识保存；同一视频的不同分 P 当前共用记录集合。

## UI 可以自行修改和设计

**当前 UI 只是默认外观，你可以自行修改配色、字体、边框、布局和控件设计。** 修改对应版本文件夹中的文件即可；两个版本各自独立，不会自动同步样式。

| 文件 / 代码 | 用途 | 适合修改的内容 |
| --- | --- | --- |
| `content.css` | 视频页面内面板样式 | 颜色、字体、间距、按钮、边框、布局、尺寸、焦点样式 |
| `content.js` → `root.innerHTML` | 主面板结构 | 标题栏、工具栏、基础时间和内容表单 |
| `content.js` → `renderFields()` | 已有自定义栏渲染 | 文本框、单选圆点、标题旁操作、文本颜色入口 |
| `content.js` → `renderBuilder()` | 栏位编辑器 | 名称、类型、选项编辑行、保存取消布局 |
| `content.js` → `paletteSelect()` / `colorChoices()` | 选项配色控件 | 小色块入口、颜色选项外观 |
| `content.js` → `FIELD_COLORS` / `paletteNames` | 功能颜色数据 | 可选颜色及名称；这也影响导出颜色 |
| `content.js` → `updatePanelScale()` | 字号随尺寸变化 | 缩放范围和基础字号 |
| `options.html` | 扩展设置页面 | 设置页结构和样式 |
| `manifest.json` | 扩展信息与加载配置 | 名称、描述、版本、脚本、权限、默认快捷键 |
| `xlsx-lite-v2.js` | 当前 XLSX 读写与样式实现 | 导出字体、单元格样式和文件读写 |
| `background.js` | 后台行为 | 快捷键转发、导出后自动清理 |

只换外观时，优先改 `content.css`。例如在文件末尾添加：

```css
#va-root {
  background: #f6f3ec;
  color: #181818;
  border: 1px solid #282828;
  border-radius: 4px;
}

#va-root .va-head {
  background: transparent;
  color: inherit;
}
```

颜色预览有部分背景通过 `content.js` 内联设置。若想改变默认无色底色或预设色显示，请同时检查 `renderFields()`、`colorChoices()` 和 `paletteSelect()`，不要用全局 `!important` 把用户选定的颜色全部覆盖。

调整 HTML 时保留现有 `.va-*` 类名和 `data-*` 属性，事件绑定依赖这些标识。修改后重新加载扩展、刷新视频页，并检查展开收起、时间记录、栏位增改删、配色、拖动缩放、全屏和 XLSX 导入导出。修改 UI 不需要服务器、API Key 或额外框架。

## 常见问题

**看不到面板？** 确认启用了正确版本、当前页面属于支持的网站且包含视频播放器，重新加载扩展后刷新视频页。网站播放器结构变化也可能影响识别。

**出现两个面板？** 检查是否同时启用了多个版本；保留一个启用即可。

**扩展更新后页面仍报错？** 旧页面可能还运行旧脚本，刷新页面后再试。

**颜色没有保存？** 栏位修改需要保存栏位编辑器；批注内容与文本颜色需要保存批注表单。

**Excel 打不开或不能导入？** 使用当前版本重新导出；导入请使用 `.xlsx` 和对应语言的表头。不要仅修改文件扩展名来转换格式。

**切换版本后数据不见了？** 不同版本的扩展存储独立；在原版本导出，再在目标版本导入，并注意表头语言。

## 开发说明

使用 Chrome Manifest V3、原生 JavaScript 和 CSS。`manifest.json` 实际加载的是 `xlsx-lite-v2.js`。仓库中的预览图片和测试文件不参与扩展运行。
